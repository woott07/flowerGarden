1. HIGH-LEVEL CONCEPT & WORKFLOW
------------------------------------------------------------------------------
Flower Wand transforms your webcam into an interactive magic wand. 

Here is the flow of what happens 60 times every second (60 FPS):

[ Web Camera Feed ]
        │
        ▼
[ MediaPipe AI Model ] ──► Detects 21 3D Joint Coordinates on your hand
        │
        ▼
[ Gesture Classifier ] ──► Is index finger pointing? Or hand open wide?
        │
        ├─────────────► Pointing?  ──► Add a flower at fingertip position
        └─────────────► Open Palm? ──► Explode flowers with physics gravity!
        │
        ▼
[ HTML5 Canvas Render Loop ] ──► Draws stems, growing flowers, and scattering petals

2. KEY CONCEPTS & AI MAGIC EXPLAINED
------------------------------------------------------------------------------

2.1 HAND LANDMARKS (21 KEYPOINTS)
---------------------------------
MediaPipe is a machine learning library built by Google. When your camera is 
on, MediaPipe analyzes each video frame and outputs 21 point coordinates (x, y, z) 
representing your hand joints:
  - Point 0: Wrist
  - Point 4: Thumb tip
  - Point 8: Index finger tip (This is your "Wand Tip"!)
  - Point 12: Middle finger tip
  - Point 16: Ring finger tip
  - Point 20: Pinky finger tip

Each point has normalized coordinates between 0.0 and 1.0. To convert them 
to screen pixels, we multiply x by canvas width and y by canvas height.


2.2 GESTURE DETECTION MATH (POINTING vs. OPEN PALM)
---------------------------------------------------
How does the code know if you are pointing or holding your hand open?
It uses geometry (distance measurements):

- POINTING GESTURE:
  We check if the Index fingertip (Point 8) is far away from the wrist (Point 0), 
  while Middle, Ring, and Pinky fingertips are curled close to the palm.
  If Index is extended AND other fingers are curled -> TRIGGER POINTING!

- OPEN PALM GESTURE:
  We check if ALL 4 main fingertips (Index 8, Middle 12, Ring 16, Pinky 20) 
  are simultaneously extended far away from the wrist.
  If all fingers are extended -> TRIGGER SCATTER EXPLOSION!


2.3 SMOOTHING FILTER (REMOVING JITTER)
--------------------------------------
Webcam video naturally has minor flicker, and human hands tremble slightly. 
If we used raw coordinates directly, flower lines would look jagged and shaky.

We solve this using Exponential Moving Average (EMA) smoothing:
  SmoothedX = (PreviousSmoothedX * 0.65) + (NewCoordinateX * 0.35)

This creates a silky-smooth fluid movement like a digital paintbrush!


2.4 PROCEDURAL BOTANICAL ART (VECTOR MATH)
------------------------------------------
Instead of loading static PNG images for flowers, Flower Wand draws every 
flower procedurally using HTML5 Canvas 2D math operations:

- Daisies: 14 white radial ellipses around a golden yellow gradient circle.
- Sunflowers: 18 golden pointed quadratic curves around a brown seed disc.
- Wild Roses: 4 layered circles of crimson petals with a center spiral.
- 4-Leaf Clovers: 4 green heart-shaped Bezier curves with leaf veins.
- Stems: Smooth quadratic curve vines connecting adjacent flower points with
  small green teardrop leaf sprouts.


2.5 PHYSICS ENGINE (SCATTER EXPLOSION)
--------------------------------------
When an Open Palm gesture is detected:
1. Every flower attached to a stem breaks free (`isStemConnected = false`).
2. Each flower is given a radial velocity vector pushing away from the palm center.
3. In the render loop, we apply physics formulas:
     PositionX += VelocityX
     PositionY += VelocityY
     VelocityY += 0.35        (Gravity pulling down)
     VelocityX *= 0.97        (Air resistance drag)
     Opacity   -= 0.008       (Fade out gradually)

3. STEP-BY-STEP FILE ARCHITECTURE
------------------------------------------------------------------------------

1. `index.html`
   - The webpage skeleton.
   - Contains `<video>` element for the webcam feed.
   - Contains `<canvas id="garden-canvas">` for rendering flowers and stems.
   - Contains `<canvas id="skeleton-canvas">` for drawing glowing hand joints.
   - Contains the top Glassmorphic HUD header with buttons & dropdowns.

2. `style.css`
   - Defines the visual design system.
   - Uses dark obsidian background (`#0b0f0c`) and glassmorphic blur effects 
     (`backdrop-filter: blur(16px)`).
   - Mirrors the video feed horizontally (`transform: scaleX(-1)`) so moving 
     your real hand right moves the screen cursor right (like looking in a mirror).

3. `src/camera.js` (CameraManager)
   - Requests access to your webcam using `navigator.mediaDevices.getUserMedia()`.
   - Starts playing the video stream and manages video resolution.

4. `src/tracker.js` (HandTracker)
   - Loads the MediaPipe AI HandLandmarker model.
   - Processes video frames and applies EMA coordinate smoothing.
   - Runs gesture classification algorithms.
   - Draws the optional glowing hand skeleton debug view.

5. `src/flowerPainter.js` (FlowerPainter)
   - Contains vector math drawing functions for all 6 flower species.
   - Draws organic stems and leaves connecting sequential flower nodes.

6. `src/gardenEngine.js` (GardenEngine)
   - The heart of the animation engine!
   - Stores arrays of active flowers and connected stroke stems.
   - Animates flower bloom growth (`scale: 0.1 -> 1.0`) and gentle ambient wind sway.
   - Runs the scatter physics simulation.

7. `src/ui.js` (UIManager)
   - Connects button clicks (Clear, Save Snapshot, Skeleton Toggle, Camera Toggle, 
     Flower Species Picker) to engine callbacks.
   - Updates the bottom floating instruction pill ("Point to plant · Open hand to scatter").

8. `src/app.js` (App Orchestrator)
   - The master conductor connecting all modules together.
   - Runs the main `requestAnimationFrame` 60 FPS loop.
   - Adds mouse & touch fallbacks so users without a webcam can still click 
     and drag to draw flowers!

4. HOW TO MODIFY AND CUSTOMIZE THE CODE
------------------------------------------------------------------------------

Want to tweak the app? Here are simple beginner modifications you can try:

- Change Flower Sizes:
  In `src/gardenEngine.js`, find `baseSize = 24 + Math.random() * 18` and 
  increase `24` to `40` for huge giant flowers!

- Change Flower Colors:
  In `src/flowerPainter.js`, edit color hex codes (e.g. `'#facc15'` for sunflowers 
  or `'#f43f5e'` for roses) to customize your color palette.

- Adjust Physics Gravity:
  In `src/gardenEngine.js`, find `f.vy = f.vy * 0.97 + 0.35` and change `0.35` 
  to `0.1` for low-gravity floating space flowers!
